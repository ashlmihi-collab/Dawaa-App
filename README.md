
# Dawaa-App | دوائي

Dawaa - دوائي | A personal medication reminder app for Android.

## Version 1.1

Features:
- Arabic and English language support.
- Medication reminders.
- Ringtone library with 14 alarm tones.
- Adjustable alarm volume.
- Customizable snooze duration.
- Vibration settings.

## Run Locally

Requirements: Node.js

1. Install dependencies:
   `npm install`
2. Configure your Gemini API key in `.env.local` if required.
3. Start the app:
   `npm run dev`

## Android

Package: `com.dawaa.reminder`

Built with React, Capacitor, and Android Studio.
